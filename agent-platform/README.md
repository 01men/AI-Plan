# 榕器 · Agent 人机协作平台

金华聚杰电器《AI数智化企业应用推广行动方案》的落地支撑底座：一个 AI 原生的人机协作平台，把 65 个数字员工当作"正式员工"纳入 5 平台 / 28 部门的组织架构，覆盖从场景立项、派活执行、人工审核到 KPI 度量、费用治理的完整闭环。

**AI 原生人机协作理念**

- **沟通即协作**：Agent 协作区默认使用真实模型连续对话深化项目；需要形成正式交付时，一键切换“正式派活交付”进入审核闭环。
- **Agent 是员工**：数字员工有组织归属、有责任人、有技能清单、有 KPI（任务量/节省工时/准确率），与人类员工同台管理。
- **三区交互**：每个工作区分为讨论区（公开研讨）、Agent 协作区（连续模型对话/正式派活）、私聊打磨区（需求草稿）。
- **人在环路审核**：数字员工的交付物一律"待人工审核"，通过才计入绩效，驳回则自动重做；写回动作必须人工确认并留痕。
- **心跳主动服务**：项目管理智能体每 6 小时自动巡检一次（也可手动触发），在经营驾驶舱发布运营日报并催办 24 小时内临期的任务。

## 一、一键启动

**前提**：Windows + Python 3.10 及以上（已在 Python 3.13 验证），并安装依赖：

```bash
python -m pip install -r requirements.txt
```

**方式一（推荐）**：双击项目根目录下的 `启动平台.bat`，服务启动后约 3 秒自动打开浏览器。

**方式二（命令行）**：

```bash
cd agent-platform
python -m uvicorn app.main:app --port 8000
```

然后访问 <http://localhost:8000>。

首次启动会自动创建 `data/platform.db` 并播种演示数据（48 名员工、65 个数字员工、
232 个场景容量位、1000 条制造业务展示数据、20 个 Skill、6 个知识空间等），无需任何手工初始化。
其中 81 个为已定义业务场景，151 个是按方案部门配额建立、明确标记为“待部门提报”的储备位。

## 二、演示身份与权限

登录页从组织人员中选择身份，免密登录（演示环境），token 存于浏览器 localStorage。

| 层级 | 人数 | 代表身份 | 权限差异 |
| ---- | ---- | -------- | -------- |
| `boss` 董事长 | 1 | 董事长 | 全部功能 + 任务审核 + 报销审批 |
| `coach` 教练团 | 4 | 李乐平 / 师圆圆 / 付玉虎 / 莫柳金 | 全部功能 + 任务审核 + 报销审批 |
| `backbone` 业务骨干 | 4 | 各平台业务负责人 | 全部功能 + 任务审核 + 报销审批 |
| `developer` 开发者 | 30 | 胡鑫（国际销售部）等 AI 应用开发者 | 可派活、建设本人部门数字员工、申报场景/激励/报销；看不到审计与越权审批 |
| `staff` 使用人 | 9 | 一线使用人员 | 仅协作空间、本人任务、可读知识；只见本人工作区和本人治理记录 |

> 审核与审批按钮（任务通过/驳回、报销三级审批）仅 `boss` / `coach` / `backbone` 三层可见，体现"人在环路"的权责设计。建议演示路径：先用开发者"胡鑫"派活，再切换董事长或教练审核。

## 三、功能导览

1. **驾驶舱**：KPI 总览（场景覆盖率、审核通过率、节省工时、年化效益）、14 天趋势、四波次进度、数字员工排行榜、实时动态流，可一键手动触发心跳。
2. **协作空间**：三区交互的 IM 式工作区；默认选择数字员工进行连续模型对话，可结合项目历史、授权知识和业务数据持续深化，也可切换正式派活并在交付卡片中审核。
3. **数字员工**：65 个数字员工台账，按平台/波次/状态/类别筛选，查看画像、绑定场景、近 14 天指标与近期任务。
4. **场景库**：承载方案 232 个部门场景容量（81 个已定义 + 151 个待部门提报储备位），支持敏捷申报与一键立项——立项即自动创建项目工作区并拉入关联数字员工。
5. **任务中心**：待处理/进行中/待审核/已通过/已驳回五列看板，人工审核通过后自动计入数字员工绩效，驳回后引擎自动重做一轮。
6. **Skill 库**：可复用技能资产库（公开/组织/个人三级），被数字员工引用的技能计入复用 KPI。
7. **知识库**：6 套群晖 DS925+ NAS 空间，文档按 L1-L4 密级分级管理；内置 1000 条制造业务展示数据。
8. **组织通讯录**：5 平台 28 部门 48 人的组织树，人与其名下数字员工同屏呈现。
9. **治理中心**：激励申报（火花奖/银齿轮奖/金扳手奖/种子基金）、大模型 token 费用报销三级审批（平台长→数字化复核→财务）、全量审计留痕、六大红线公示。
10. **项目流程**（V3 泳道图承载）：每个立项场景自动生成 N01–N40 五阶段流程（8 角色泳道矩阵），智能体自动推进 60% 节点，🤝节点 AI 起草人类确认，G1–G4 阶段门由决策层签核解锁，关键路径延迟自动预警。
11. **路线图**：筑基/推广/深化三阶段 15 个里程碑与四波次（8-11 月）推进计划。
12. **模型配置（R4）**：内置 GLM/Kimi/MiniMax/DeepSeek/通义千问五家 OpenAI 兼容模型，全局默认 + 单数字员工覆盖绑定，界面配置 Key 即用，未配置自动回落模板模拟。
13. **Skill 维护与 Agent 自定义（R4）**：Skill 库支持增删改；数字员工可新建/改名/调部门，并绑定技能与 MCP 服务台账（ERP 只读/钉钉消息/NAS 检索）。
14. **知识库上传解析（R4/R6）**：txt/docx/pdf/Excel/csv/json/html 一键上传；Excel 全工作表分别转 SQLite 表并生成 CSV，可在线预览、下载和供数字员工检索。
15. **IM 绑定（R4）**：钉钉/飞书 OAuth 授权绑定，未配置凭证时提供演示模式一键模拟绑定。
16. **执行链路可视化（R4）**：协作空间按"过去→现在→未来"聚合任务事件与项目流程后续节点，一览执行全貌。

## 四、接入真实大模型

平台默认使用**模板模拟**生成交付物（不联网、零成本、可离线演示）。R4 起内置 5 家国内主流模型
（智谱 GLM / Kimi / MiniMax / DeepSeek / 通义千问，均为 OpenAI 兼容接口），推荐直接调 API 配置：

```bash
# 配置某家模型的 Key（boss/coach 身份）
curl -X PUT http://localhost:8000/api/models/glm \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"api_key": "你的 API Key"}'
# 切换全局默认模型
curl -X PUT http://localhost:8000/api/models/default \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" -d '{"key": "deepseek"}'
```

- **全局默认 + 单员覆盖**：`settings.default_model_key` 为全局默认；`PATCH /api/agents/{id} {"model_key":"kimi"}`
  可让某个数字员工单独绑定模型（为空则跟随全局）。
- **无需重启**：引擎每次生成时实时解析配置；Key 未配置、供应商停用、调用超时或失败会回落模板，
  同时在任务上记录 `execution_mode / model_provider / execution_error / execution_ms`，界面明确提示而非静默伪装。
- **对话不模拟**：连续对话模式必须调用数字员工绑定模型；未配置或调用失败时明确显示原因，
  不用交付模板冒充模型回复。正式派活模式仍可按原规则回落模板以保障业务可追踪。
- **凭证保护**：API Key 和钉钉/飞书 Secret 使用 AES-256-GCM 加密落库；主密钥位于
  `data/master.key`（或用 `PLATFORM_MASTER_KEY` 环境变量提供），生产备份必须同时安全备份该密钥。
- **向后兼容**：旧的 `settings.llm_base_url / llm_api_key / llm_model` 三键仍然有效且优先级最高
  （配置了三键则忽略 model_providers），删除即恢复按 model_providers 解析。

## 六、数据重置

删除 `data/platform.db`，重新启动服务（或再次双击 `启动平台.bat`）即可自动重新建表并播种，
恢复到初始演示状态。注意：这样也会清除运行数据、模型和 IM 配置，操作前请备份数据库与
`data/master.key`。种子规模：5 平台 / 28 部门 / 48 人 / 65 数字员工 /
232 场景容量位 / 1000 条制造业务展示数据 / 20 Skill / 6 知识空间 / 15 里程碑。

## 七、技术栈

- **后端**：Python + FastAPI + SQLite（无 ORM）；`openpyxl/xlrd` 解析 Excel，`cryptography` 保护凭证，`qrcode` 同源生成 IM 二维码；
  心跳为 `asyncio` 后台任务，每 6 小时执行一次。
- **前端**：原生 HTML/JS/CSS 单页应用（无构建步骤），Tailwind/ECharts/二维码脚本已随项目本地化，
  断公网仍可打开；登录 token 存 localStorage，服务端 12 小时过期且支持主动撤销。
- **大模型适配**：`urllib` 调 OpenAI 兼容接口，未配置或失败时回落模板并完整留痕，可离线演示。
- **接口约定**：见 `API.md`（全部端点、请求体与真实响应示例）。
